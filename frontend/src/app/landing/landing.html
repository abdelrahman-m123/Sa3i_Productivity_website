01 / Structured generation

AI proposes the work

Gemini returns structured task proposals. The backend validates titles, estimates, priorities, and categories before scheduling.

02 / Scheduling logic

The server finds the time

A separate scheduler considers working hours and existing bookings. Availability is checked again when a plan is confirmed.

03 / Authenticated access

Tasks belong to a user

JWT authentication identifies the user. Standard task reads, edits, and deletes query both the task and its owner.
